0.39.0
da3164f

Rerun is an easy-to-use database and visualization toolbox for multimodal and temporal data.

  • Python: pip install -U rerun-sdk
  • Rust: 0.39.0 is not published on crates.io, since it depends on an unreleased version of egui. The rerun CLI is available via pip install rerun-sdk or the binaries attached to this release.
  • C++ FetchContent: https://github.com/rerun-io/rerun/releases/download/0.39.0/rerun_cpp_sdk.zip
  • Online demo: https://rerun.io/viewer

✨ Overview & highlights

  • Text in any language, and color emoji 🚀 希望你喜欢这个

  • Rerun Viewer in marimo notebooks

  • Raw Bayer images

  • PLY mesh and 2D point support

  • Playback controls for segment previews

  • Configure the state timeline time axis

  • State timeline hover duration

  • String literals in lens selectors

  • Improved table column settings, with search, display mode and bulk hide/show

    Video

🧪 Experimental and unstable

These may change in future releases, and unstable types may not stay backwards compatible.

  • Raymarched 3D volumes

    Video

  • Audio: AssetAudio archetype and AudioView

  • New table blueprints with Python table API

📖 Release notes: https://rerun.io/docs/changelog/changeset-0-39#highlights

⚠️ Breaking changes

  • rerun-sdk installs rerun as a top-level package
  • WriteChunks removed
  • Breaking changes to custom Rust views

🧳 Migration guide: https://rerun.io/docs/changelog/changeset-0-39#breaking-changes
