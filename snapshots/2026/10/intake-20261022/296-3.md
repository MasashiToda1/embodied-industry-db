In-hand cube reorientation for the Wuji Hand 2, trained with [rsl_rl](https://github.com/leggedrobotics/rsl_rl)
PPO on [Isaac Lab](https://github.com/isaac-sim/IsaacLab) 2.3.2 and Isaac Sim 5.1.

## Repository Structure

```text
wuji-isaaclab/
├── src/wuji_isaaclab/
│   ├── assets/                    // Wuji Hand 2 and cube configs
│   ├── rl/                        // rsl-rl runner, config, ONNX export
│   └── tasks/reorient/            // reorientation env and MDP terms
├── scripts/
│   ├── rsl_rl/                    // train / play
│   └── tools/                     // smoke and diagnostic tools
├── third_party/wuji-description/  // submodule: Wuji Hand 2 USD assets
├── docker/                        // optional container build
└── pixi.toml                      // environment + tasks
```

## Installation

Requires Linux x86_64 with glibc >= 2.35, an NVIDIA GPU with driver >= 580.65.06 and [pixi](https://pixi.sh)
(tested with 0.72.0).

```bash
git clone --recursive https://github.com/wuji-technology/wuji-isaaclab.git
cd wuji-isaaclab
git submodule update --init   # only if cloned without --recursive
pixi install
```

## Training and Play

```bash
pixi run train --task Wuji-Hand2-Reorient-v0 --headless
pixi run play --task Wuji-Hand2-Reorient-Play-v0
```

Training defaults to 16384 environments; use `--num_envs` to fit smaller GPUs. `play` loads the latest checkpoint
under `logs/rsl_rl/wuji_hand2_reorient/` (or the one given by `--checkpoint`) and exports `policy.pt`,
`policy.onnx` and `config.json` to `exported/` next to it.

## Task

Reorient a cube in the palm of a fixed-base Wuji Hand 2 to randomly sampled target orientations.

## Sim2Real Deployment

Exported policies use exactly the same observation, action and `config.json` definition as
[wuji-mjlab](https://github.com/wuji-technology/wuji-mjlab), so they run on its real-hand deployment stack. With the rig
set up as described in its [Sim2Real guide](https://github.com/wuji-technology/wuji-mjlab/blob/main/docs/external/en/sim2real.mdx),
run each command in its own terminal from a wuji-mjlab checkout:

```bash
pixi install -e deploy
pixi run -e deploy home                     # one-shot reset
pixi run -e deploy vision                   # cube observer, keeps running
pixi run -e deploy play-real --ckpt <wuji-isaaclab>/logs/rsl_rl/wuji_hand2_reorient/<run>/exported/policy.onnx
```

`config.json` is read from the same directory as `policy.onnx`.
