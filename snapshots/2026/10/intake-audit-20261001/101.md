# pi05_rb10_iros_ee_30k

JAX (openpi / pi0.5) policy checkpoint for the Rainbow Robotics RB10 end-effector control demo (step 30000).

Contents: `params/` (orbax), `assets/rb10_iros_ee/norm_stats.json`, `_CHECKPOINT_METADATA`.
Serve it with the `pi05_rb` inference bundle, config `pi05_rbc10_iros_ee`:

```bash
bash inference download rainbowrobotics/pi05_rb10_iros_ee_30k
bash inference pi05_rb10_iros_ee_30k
```
