开始使用

让机器人理解你的指令，并根据它看到的场景行动。

RoboAPI 将相机画面、机器人状态和任务指令交给 Poke-Aurora，返回接下来要执行的动作。你可以使用本地控制台连接机器人，也可以把推理 API 接入自己的程序。

1. 获取 API Key

登录 开发者控制台，创建用于调用模型的 API Key，并查看账户可用模型与额度。具体步骤见 账户与 API Key。

2. 选择接入方式

使用自己的机器人

准备设备、安装 RoboAPI，在浏览器里查看画面并下达任务。

从代码调用模型

发送一张图片、当前状态和指令，读取第一段动作结果。

使用自己的机器人：在连接设备的 Linux 控制电脑上运行 RoboAPI。它负责采集观测、请求动作并执行；你的个人电脑按安装指南建立 SSH 转发后，通过浏览器操作本地控制台。先看 硬件准备，再完成 安装 和 标定。RoboAPI 会自动管理任务会话与执行回执。

从代码调用模型：使用 OpenAI Python SDK、JavaScript 或 HTTP 请求云端 API。你负责采集观测、将动作转换为控制器指令并执行。先完成 第一次调用，再查阅 观测与动作 和 API 参考。

3. 运行一个任务

完成设备配置、标定和模型连接后，在 本地控制台 输入一个清晰、可观察的任务，例如“把蓝色衣服展开”，点击发送或按 Shift+Enter 开始。机器人会根据新的画面持续请求动作；需要停止时点击 Robot Stop。

任务中的物体应保持在相机视野内。首次运行时，从简单任务开始，确认动作方向、夹爪与实际工位一致。

如果模型表现不正常，请先按常见问题中的检查清单逐项检查。

控制电脑上的 http://127.0.0.1:8080/连接设备、查看画面、运行与停止机器人

开发者控制台管理云端账户；机器人操作在你自己的控制电脑上进行。需要自动化集成时，使用 本地 HTTP API 或 MCP 工具。

接入其他机器人或开发完整硬件适配器时，继续接入新硬件；组件接口见硬件适配接口。
