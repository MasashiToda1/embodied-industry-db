spanning cloud GPU training, cross-cluster collaboration, and edge device deployment across heterogeneous resources such as GPU clusters, robot arms, sensors, and cameras.\nExplore the complete documentation on\nRead the Docs\n— start with the\nQuick Start\n, then continue with the\nplatform user guide\nor\nadministrator guide\n.\nWhat's NEW!\n[2026/09] RLark is now open-source.\nKey Capabilities\nEmbodied AI Workload Orchestration\n: From cloud GPU training (RL/LLM) to edge deployment (robot arm, sensor, camera), unified declarative Job/Task abstraction across the full pipeline\nMulti-Runtime Data Plane\n: Kubernetes provides unified management for cloud GPU clusters and edge devices across the complete training-to-deployment lifecycle; Docker and Raw runtime support will extend coverage to lightweight edge scenarios where Kubernetes is not suitable\nCross-Cluster Resource Abstraction\n: Unify multi-site GPU clusters and edge devices via Domain (virtual network domain) and Node (compute node) CRDs, with the control plane running on kcp\nDeclarative Training Jobs\n: Job/Task abstraction with declarative distributed training and Ray cluster definition\nCross-Cluster Pod Networking\n: Virtual network based on TUN devices + gVisor netstack + SSH tunnels, enabling Pod-to-Pod communication without NAT traversal — cloud GPUs and edge robots communicate directly\nCertificate System\n: Dual-layer X.509 + SSH certificates for Agent access, Domain-scoped cross-cluster forwarding authentication, and user SSH authentication\nObservability\n: Prometheus metrics, real-time Pod log streaming, and web management UI\nRoadmap\nSee the\nRLark Roadmap\nfor planned runtime, account management, and custom workload resource improvements.\nArchitecture Overview\nQuick Start\nFollow the\nQuick Start Guide on Read the Docs\nto choose one of the verified flows:\nOne-click CLI\n: deploy the control plane and two kind data-plane clusters, then verify cross-cluster Pod networking.\nUI-based flow\n: create clusters and a Domain in the web console, deploy two kind data planes, schedule a Job across them, and verify connectivity.\nDocumentation\nThe complete, searchable, and versioned documentation is published on\nRead the Docs\n.
